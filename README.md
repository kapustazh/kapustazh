## Selected work

**[OneShot](https://github.com/kapustazh/oneshot)** · [live demo](https://oneshot.kapustazh.dev)  
Stablecoin payments for AI agents: reliable execution and settlement of approved intents. A TypeScript system with API, worker, and UI services, PostgreSQL, MCP, and tests.  
`TypeScript` `PostgreSQL` `MCP` `Web3`

**[DeepTrace](https://github.com/ikodo0/deeptrace)** · [showcase](https://ethglobal.com/showcase/deeptrace-7fqoz)  
An MCP server that gives AI agents verifiable DeFi data on Base, with source attribution and freshness checks so answers don't rest on hallucinated numbers. 🏆 3rd place, Best AI Tooling (The Graph), ETHGlobal Lisbon 2026.  
`TypeScript` `MCP` `The Graph` `Base`

**[call_me_maybe](https://github.com/kapustazh/call_me_maybe)**  
A small-model function-calling pipeline that picks the right tool and generates typed parameters with constrained decoding, instead of free-form JSON. Built around Qwen3-0.6B.  
`Python` `Pydantic` `Constrained decoding`

**[my_rag](https://github.com/kapustazh/my_rag)**  
A retrieval-augmented generation pipeline built around semantic vector search and custom embeddings. Active research.  
`Python` `LLM tooling` `Vector indexing`
